ನನಗೆnanageto me
ನೀರುneeruwater · item
ಬೇಕುbekuwant / need

ನನಗೆ ನೀರು ಬೇಕು (Nanage neeru beku) means “I want water.” Replace ನೀರು (neeru, water) with ಚಹಾ (chahaa, tea) or ಕಾಫಿ (kaafi, coffee). Replace ಬೇಕು (beku) with ಬೇಡ (beda) to decline it.

Try it: ನನಗೆ ಚಹಾ ಬೇಡ · Nanage chahaa beda. “I don't want tea.”

Today's mission

Read the words →

Practice a two-choice exchange with a friend, or say it aloud twice:

  1. Ask for water: ನನಗೆ ನೀರು ಬೇಕು (Nanage neeru beku) · I want water
  2. Decline tea: ನನಗೆ ಚಹಾ ಬೇಡ (Nanage chahaa beda) · I don't want tea

Then swap in coffee using the same pattern. In a real request, add ದಯವಿಟ್ಟು (dayavittu, please) to be polite.

New Kannada wording, romanization and generated speech still need review by a fluent speaker. English is a learning aid, not a word-for-word translation.
